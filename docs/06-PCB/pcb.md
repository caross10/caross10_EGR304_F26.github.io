# PCB Design

## Optical Sensor Monitoring Subsystem

This page documents the completed PCB design for the Optical Sensor Monitoring Subsystem developed as part of the Automatic Pet Food Dispenser project.

The PCB was designed using KiCad and incorporates the optical sensor, signal conditioning circuitry, voltage regulation, and microcontroller connections required to monitor the movement of the dispensing mechanism and identify potential faults.
